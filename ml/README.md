# AHHE Machine Learning Experiments & Pipelines

This directory contains standalone Python scripts, Jupyter notebooks, feature engineering pipelines, and training scripts for the AHHE platform's advanced AI/ML models:

## Key Modules
1. **Dynamic Festival Pricing Engine (`pipelines/training.py`)**: Predicts optimal room pricing during Uttarayan, Navratri, and Diwali demand surges.
2. **Trust & Authenticity Score Algorithm (`pipelines/feature_engineering.py`)**: Generates composite host/listing trust metrics based on verification, reviews, response times, and heritage parameters.

## Directory Structure
- `notebooks/`: Exploratory Data Analysis (EDA) and prototype notebooks.
- `pipelines/`: Data preprocessing, feature extraction, and model training pipelines.
- `models/`: Serialized model artifacts (`.pkl` / `.joblib`).
- `evaluation/`: Model evaluation and performance tracking metrics.
